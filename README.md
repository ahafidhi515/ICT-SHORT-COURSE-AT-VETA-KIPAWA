# ICT SHORT COURSE AT VETA KIPAWA

Mobile learning application for ICT short courses at VETA Kipawa.

## Features

- User Registration
- User Login
- Course Listing
- Course Notes
- Firebase Firestore Integration
- PDF Notes Access

## Project Setup

Install dependencies:

```bash
npm install
```

Run project:

```bash
npx expo start
```
